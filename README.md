5. Опишите основные плюсы и минусы pull и push систем мониторинга.

Push: 
Плюсы: Легко работает за NAT и Firewall (серверу не нужен доступ к клиентам).
Идеально для короткоживущих задач (скрипты отправили данные и завершились).
Можно использовать UDP для снижения нагрузки на сеть.

Минусы: Сложно узнать, что хост «умер» (он просто перестает слать данные).
Есть риск перегрузить сервер мониторинга (DDOS), если наплыв метрик будет слишком большим.

Pull:
Плюсы: Сервер сразу видит смерть хоста (если тот не ответил на опрос).
Централизованный контроль над частотой опроса и списком хостов.
Простая отладка (можно проверить метрики обычным браузером в формате текста).

Минусы: Нужно открывать сетевые порты на каждом хосте для сервера мониторинга.Не подходит для коротких задач (сервер не успеет прийти за метриками до их завершения).
