# Домашнее задание к занятию «Введение в микросервисы»

## Задача

Руководство крупного интернет-магазина, у которого постоянно растёт пользовательская база и количество заказов, рассматривает возможность переделки своей внутренней   ИТ-системы на основе микросервисов. 

Вас пригласили в качестве консультанта для оценки целесообразности перехода на микросервисную архитектуру. 

Опишите, какие выгоды может получить компания от перехода на микросервисную архитектуру и какие проблемы нужно решить в первую очередь.

### Ответ:

### Выгоды от перехода на микросервисыНезависимое масштабирование: 

1. Независимое масштабирование: Можно увеличивать мощности только для нагруженных узлов (например, корзины или поиска), не дублируя всю систему целиком
2. Отказоустойчивость: Сбой в модуле рекомендаций или отзывов не остановит оплату и оформление заказов.
3. Ускорение разработки: Автономные команды создают, тестируют и выпускают свои сервисы независимо, сокращая время выкатки фич (Time-to-Market).
4. Свобода выбора технологий: Для разных задач (поиск, аналитика, биллинг) можно использовать наиболее подходящие языки программирования и базы данных.
5. Упрощение кодовой базы: Новым разработчикам легче адаптироваться, изучая изолированные небольшие сервисы, а не гигантский монолит.

### Первоочередные проблемы, которые нужно решить:

1. Сложность координации данных: Необходимо внедрить механизмы распределенных транзакций для сохранения консистентности данных между сервисами.
2. Инфраструктурные затраты: Требуется развернуть и настроить оркестраторы контейнеров , API-шлюзы и сервисную сетку.
3. Сквозной мониторинг и трассировка: Нужно сразу выстроить централизованный сбор логов и распределенную трассировку для быстрого поиска ошибок.
4. Безопасность межсервисной среды: Требуется настроить взаимную аутентификацию сервисов и централизованное управление правами доступа.
5. Организационная перестройка: Необходимо перестроить ИТ-департамент по принципу «один сервис — одна автономная команда» (закон Конвея), обеспечив сильные DevOps-компетенции.
