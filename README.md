Домашнее задание — важная часть вашего обучения. Оно поможет закрепить знания и развить необходимые для профессиональной жизни навыки. Подходите к этому заданию с энтузиазмом и уверенностью — помните, что каждый шаг вперед делает вас сильнее и ближе к достижению ваших целей.

Описание задания

Познакомьтесь с различными видами досок, которые предлагает Kaiten, пройдите весь путь задачи до её завершения.

Что нужно сделать?

1. Настройка доски

Создайте пространство и добавьте новую доску типа Scrum.
Добавьте новую колонку в «Готово для тестирования», переместите колонку так, чтобы она была после колонки «В работе».

3. Создание задачи по Backend

Создайте две задачи в Backlog доске, например «Backend — Integration with YandexPay».

#### screenshot 01

![01](https://github.com/yojihc/netology-Virtualization/blob/09-jira-01-kaitan/pics/backend/01.png?raw=true)

#### screenshot 02

![02](https://github.com/yojihc/netology-Virtualization/blob/09-jira-01-kaitan/pics/backend/02.png?raw=true)
