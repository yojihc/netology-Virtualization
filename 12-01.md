# Домашнее задание к занятию «Базы данных»

### Задание 1

Опишите не менее семи таблиц, из которых состоит база данных. Определите:

- какие данные хранятся в этих таблицах,
- какой тип данных у столбцов в этих таблицах, если данные хранятся в PostgreSQL.

Начертите схему полученной модели данных. Можете использовать онлайн-редактор: https://app.diagrams.net/

Этапы реализации:
1.	Внимательно изучите предоставленный вам файл с данными и подумайте, как можно сгруппировать данные по смыслу.
2.	Разбейте исходный файл на несколько таблиц и определите список столбцов в каждой из них. 
3.	Для каждого столбца подберите подходящий тип данных из PostgreSQL. 
4.	Для каждой таблицы определите первичный ключ (PRIMARY KEY).
5.	Определите типы связей между таблицами. 
6.	Начертите схему модели данных.
На схеме должны быть чётко отображены:
   - все таблицы с их названиями,
   - все столбцы  с указанием типов данных,
   - первичные ключи (они должны быть явно выделены),
   - линии, показывающие связи между таблицами.

**Результатом выполнения задания** должен стать скриншот получившейся схемы базы данных.

#### Ответ:

1. Таблица "Сотрудники" (employees)

- employee_id (SERIAL) - PRIMARY KEY
- full_name (VARCHAR(100)) - ФИО сотрудника
- position_id (INTEGER) - ссылка на должность
- department_id (INTEGER) - ссылка на подразделение
- hire_date (DATE) - дата найма
- salary (DECIMAL(10,2)) - оклад

2. Таблица "Должности" (positions)

- position_id (SERIAL) - PRIMARY KEY
- position_name (VARCHAR(50)) - название должности

3. Таблица "Типы подразделений" (department_types)

- type_id (SERIAL) - PRIMARY KEY
- type_name (VARCHAR(30)) - название типа (Отдел, Группа, Департамент)

4. Таблица "Подразделения" (departments)

- department_id (SERIAL) - PRIMARY KEY
- department_name (VARCHAR(100)) - название подразделения
- type_id (INTEGER) - ссылка на тип подразделения
- branch_id (INTEGER) - ссылка на филиал

5. Таблица "Филиалы" (branches)

- branch_id (SERIAL) - PRIMARY KEY
- branch_address (VARCHAR(200)) - адрес филиала

6. Таблица "Проекты" (projects)

- project_id (SERIAL) - PRIMARY KEY
- project_name (VARCHAR(150)) - название проекта

7. Таблица "Назначения на проекты" (employee_projects)

- assignment_id (SERIAL) - PRIMARY KEY
- employee_id (INTEGER) - ссылка на сотрудника
- project_id (INTEGER) - ссылка на проект
